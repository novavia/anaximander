# README

Welcome to the Anaximander project!

## What is this repository for?

- Anaximander is an open-source modeling framework designed to simplify and unify the development of digital infrastructure for physical AI. See [ANAXIMANDER.md](ANAXIMANDER.md) for a more comprehensive description.
- This is a development version toward an initial 0.5.x release.
- Documentation is in the `docs/` folder (start with `docs/index.md`), and packaging/metadata is defined in `pyproject.toml`.
