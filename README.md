# README

Welcome to the Anaximander project!

- Anaximander is an open-source semantic modeling framework designed to simplify and unify the development of data platforms, particularly for applications that are tied to physical systems and involve spatio-temporal transformations. See [ANAXIMANDER.md](ANAXIMANDER.md) for a more comprehensive description.
- Anaximander is built in Python, for Python developers. It is released under the Mozilla Public License 2.0 (MPL-2.0).
- This is a development version toward an initial 0.5.x release. Do not expect feature completeness or stability at this time.
- Documentation, including foundational materials and design documents, is gathered in the `docs/` folder, and packaging/metadata is defined in `pyproject.toml`.
- Legacy prototypes of Anaximander, starting as far back as 2017, are captured on legacy branches (/nx1, /nx2, /nx3, /nx4).
- For questions and discussions, please directly contact lead developer JD Margulici at Novavia Solutions.
